# Piblio
A bi<strong>blio</strong>teca <strong>pi</strong>rata. 🏴‍☠️

O [Piblio](https://piblio.org) é um projeto dedicado ao compartilhamento livre e irrestrito de livros e documentos digitais. 

Acreditamos que o acesso ao conhecimento e a cultura são direitos universais que devem transcender barreiras financeiras e geográficas.

> “Quando o mundo estiver unido na busca do conhecimento, e não mais lutando por dinheiro e poder, então nossa sociedade poderá enfim evoluir a um novo nível.”

## 🤝 Colaboração e contato
O Piblio cresce através da comunidade. Se você deseja enviar novos livros para o acervo ou simplesmente trocar ideias sobre o projeto, sinta-se à vontade para entrar em contato.

- E-mail: [o-piblio@proton.me](mailto:o-piblio@proton.me)

> **Observe que**: Preferimos arquivos em formato ePub `.epub` por serem mais fácies de converter para outros formatos.

### 💻 Desenvolvimento e melhorias
O Piblio é um projeto de código aberto. Encorajamos desenvolvedores a contribuírem com melhorias na interface, performance, segurança e novas funcionalidades.

#### Como contribuir com código:
1. **Fork & clone**: Faça um fork do repositório e trabalhe em sua própria branch.
2. **Issue tracking**: Verifique as Issues em aberto para ver onde precisamos de ajuda ou sugira uma nova funcionalidade/correção.
3. **Pull Requests**: Ao enviar um PR, descreva claramente as mudanças. Pull Requests que melhorem a privacidade dos usuários ou a eficiência do site têm prioridade máxima.

**Oberve que**: Sempre que possível, assine seus commits utilizando uma chave GPG/PGP ou SSH vinculada ao seu perfil. Isso ajuda a garantir a integridade do código e a identificar o autor.

Caso não possua uma chave GPG ou SSH, verifique a documentação sobre o assunto feita pelo GitHub para mais informações (em português).
- [Assinar commits](https://docs.github.com/pt/authentication/managing-commit-signature-verification/signing-commits).
- Gerar uma nova chave [GPG](https://docs.github.com/pt/authentication/managing-commit-signature-verification/generating-a-new-gpg-key)/[SSH](https://docs.github.com/pt/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent).
- [Informar ao Git sobre a chave de assinatura](https://docs.github.com/pt/authentication/managing-commit-signature-verification/telling-git-about-your-signing-key).
- Adicionar sua chave [GPG](https://docs.github.com/pt/authentication/managing-commit-signature-verification/adding-a-gpg-key-to-your-github-account)/[SSH](https://docs.github.com/pt/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account) ao GitHub.

#### 🛠️ Stack tecnológica
- Linguagem: [TypeScript](https://www.typescriptlang.org/).
- Framework: [Next.js](https://nextjs.org/).
- Estilização: [Tailwind CSS](https://tailwindcss.com/).
- Componentes: [Shadcn UI](https://ui.shadcn.com/docs/components) e [Base UI](https://base-ui.com).
- Autenticação: [Better Auth](https://www.better-auth.com).
- Banco de dados: [Prisma ORM](https://www.prisma.io/orm) e [SQLite](https://www.sqlite.org/index.html).
